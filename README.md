# SQL-Project

## Bookstore Management System using PostgreSQL
SQL Database Project for Book Inventory, Customer Management and Sales Analysis

A relational database project built using PostgreSQL to manage bookstore operations. The project demonstrates database design, SQL querying, data retrieval, joins, aggregate functions, and analytical queries for managing books, customers, inventory, and sales transactions.

## Short Description / Purpose

The Bookstore Management System is designed to simulate the operations of a bookstore by managing books, customers, and orders using PostgreSQL. The project focuses on writing SQL queries to retrieve, analyze, and summarize business data through basic and advanced database operations.

## Tech Stack

The project was developed using the following technologies:

PostgreSQL – Relational Database Management System (RDBMS)
pgAdmin 4 – Database administration and query execution
SQL – Database creation, table management, joins, filtering, grouping, sorting, and aggregation
SQL Script (.sql) – Database schema and query implementation

## Database Structure

The project consists of three relational tables:

Books – Stores book details including title, author, genre, publication year, price, and stock.
Customers – Stores customer information including name, email, phone, city, and country.
Orders – Stores order transactions including customer, book, order date, quantity, and total amount.

## Features / Highlights
Business Problem

Bookstores need an efficient database system to manage inventory, customer records, and sales transactions. Manual tracking makes it difficult to retrieve information, monitor stock, calculate revenue, and analyze customer purchasing behaviour.

Goal of the Project

The objective of this project is to design a relational database and perform SQL queries that support inventory management, customer management, sales analysis, and reporting using PostgreSQL.

SQL Operations Performed
Basic Queries
Retrieve books by genre.
Find books published after a specific year.
Retrieve customers by country.
Filter orders by date.
Calculate total available stock.
Find the most expensive book.
Retrieve customers based on purchase quantity.
Filter high-value orders.
List available book genres.
Find the book with the lowest stock.
Calculate total revenue.
Advanced Queries
Calculate books sold by genre.
Find the average price of Fantasy books.
Identify customers with multiple orders.
Find the most frequently ordered book.
Retrieve the top three most expensive Fantasy books.
Calculate books sold by each author.
Find cities of customers with high-value purchases.
Identify the highest-spending customer.
Calculate remaining inventory after fulfilling all orders.
